## 操作方式

| 操作 | 使用方式 |
| --- | --- |
| 上一页 / 下一页 | 点击底部箭头，或按键盘 `←` / `→` |
| 下一页 | 页面主体获得焦点时按空格 |
| 首页 / 末页 | `Home` / `End` |
| 全屏 / 退出全屏 | 点击右上角全屏按钮，或按 `F` |
| 页面目录 | 点击右上角目录按钮，或按 `G` |
| 关闭目录 / 退出全屏 | `Esc` |
| 手机翻页 | 在演示画面上左右滑动，建议横屏观看 |

支持通过网址定位到指定页面，例如在线预览地址后加上 `#slide-6`，即可打开第 6 页。

## 在本地打开

点击仓库的 **Code → Download ZIP**，解压后双击 `index.html`。全部图片随网页一起保存，无需连接 Figma，也无需安装依赖。

## 发布到 GitHub Pages（可选）

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择仓库默认分支，目录选择 **/(root)**，点击 **Save**。
4. 等待 GitHub 部署完成，在 Pages 设置页面找到实际的网站地址。

启用后，可以用 GitHub Pages 的地址替换本文顶部的预览链接。当前顶部链接指向已发布的独立预览站；修改仓库文件不会自动更新该独立预览站。

## 文件结构

```text
index.html          # 演示网页，包含翻页、全屏和目录功能
assets/             # 16 张幻灯片画面
.nojekyll           # 让 GitHub Pages 直接发布静态文件
README.md           # 使用说明与在线预览入口
```

原稿以图片形式呈现，保留 Figma 排版与字体效果；网页同时提供文本说明，便于辅助阅读。
